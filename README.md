# The World in One Day — 19 November 2026

Entry for the make.fun bounty [Sum up 19 November's world news in one image](https://make.fun/bounty/news-image-20261119).

## The image

A newspaper front page for Thursday 19 November 2026, with six stories from that day:

- **The Hague** — the ICJ rules Myanmar committed genocide against the Rohingya
- **China** — Trump, Xi and Putin meet in Shenzhen, the first three-way summit
- **Middle East** — oil tankers hit mines near the Strait of Hormuz
- **Climate** — COP31 talks in Antalya
- **South Asia** — Bangladesh in turmoil
- **Art market** — a Van Gogh sells for a record $190.4m

Every word on the page is rendered by code, so the text is exact at any size.
The date — Thursday 19 November 2026 — is printed in the masthead, so the
day the image sums up is unmistakable.

## How it works

`main.ts` copies the pre-rendered `entry.png` (1024×1024) into the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The image itself was drawn with a small Python/PIL script using system fonts — no AI image generator was used for any text.
